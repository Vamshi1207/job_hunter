Apply in your browser

Apply opens the company form when Camoufox can read it from the posting. Easy Apply opens the LinkedIn page. Install the helper once so fields fill themselves. You still click Submit.

Chrome: chrome://extensions → Developer mode → Load unpacked → extension. On the form page, click the Job desk fill icon to upload that job's tailored CV and fill known fields. It looks inside iframes and shadow roots. If the site has no file field it can attach to, it downloads that job's PDF and copies the path (Cmd+Shift+G in the file picker, then paste). Custom questions: click or highlight the field, then the icon again — or right-click → Answer this question. It never clicks Submit.

Or Tampermonkey: userscript → menu → Fill this form. Bookmarklet fallback: drag Fill this form onto the bookmarks bar.
